# MVP

The first milestone (from `AGENTS.md` §21):

> Deliver a desktop application that can import a PDF, navigate to a specific page, create
> and save a note, highlight selected text, restart the app, and recover the note and
> highlight correctly.

Only after this milestone is stable should the project rely on AI generation as a core
workflow.

## Planned delivery order

1. Phase 0 — Project foundation (current)
2. Phase 1 — Workspace UI and local persistence
3. Phase 2 — Document import and reading
4. Phase 3 — Annotations and highlights
5. Phase 4 — AI provider infrastructure
6. Phase 5 — Contextual chat and page explanation
7. Phase 6 — Daily learning plan
8. Phase 7 — Hardening and Windows release
